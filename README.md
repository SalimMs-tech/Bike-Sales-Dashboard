# Bike-Sales-Dashboard
Project Overview
This project is an interactive Excel dashboard created to analyze customer bike purchase behavior using sales data.

The dashboard was built using Microsoft Excel and includes data cleaning, pivot tables, charts, and slicers to transform raw data into meaningful business insights.

# Features
- Data Cleaning and Preparation
- Interactive Pivot Tables
- Dynamic Dashboard Visualization
- Customer Demographic Analysis
- Region and Education Filters
- Commute Distance Analysis
- Income Comparison by Gender

# Tools Used
- Microsoft Excel 2016
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning Techniques

# Key Insights
- Middle-aged customers showed higher purchase activity.
- Customers with shorter commute distances were more likely to purchase bikes.
- Income levels influenced purchasing behavior across genders.
- Regional and educational differences affected customer decisions.
